# mādi – e-shop (pracovná verzia)

Statický web (HTML/CSS/JS), nasadzuje sa automaticky na Vercel pri každom pushi do `main`.

- `index.html` – úvod
- `produkt.html?p=<id>` – detail produktu
- `pokladna.html` – pokladňa (ukážka, platobná brána zatiaľ nie je zapojená)
- `assets/js/products.js` – **produkty, ceny, texty** (pracovné názvy a ceny – nie sú finálne)
- `assets/js/app.js` – hlavička, pätička, košík, stierací los
- `assets/css/style.css` – dizajn
- `assets/img/` – fotky produktov
